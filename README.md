# Unterrichts-Navigator V16

Der Unterrichts-Navigator verbindet den Tagesmodus mit der langfristigen Unterrichtsplanung. Das Symbol aus Sextant, Polarstern und Welle steht für Orientierung und einen sicheren Kurs im bewegten Unterrichtsalltag.

## Kernlogik

- **Mein Tag**: Stundenplan → Unterricht/Orga → Material-Packliste → konkrete Stunde.
- **Planen**: Fächer/Lerngruppen → Reihe → Kompetenzpfad → konkrete Stunde.
- Der aktuelle Kompetenzstand bleibt vom Kalender getrennt und kann jederzeit verschoben werden.
- Der Timer warnt in den letzten 20 Prozent orange und in den letzten 5 Prozent rot.
- Die App ist fachoffen; Fächer und Lerngruppen sind frei anlegbar.
- Der Reihen-Check verbindet Kontext-Export, ChatGPT-Prüfung und Ergebnis-Import.

## Datenschutz und Speicherung

Die App ist vollständig statisch. Unterrichtsdaten werden ausschließlich im lokalen Browser gespeichert. Für wichtige Daten regelmäßig **Backup** verwenden und keine personenbezogenen Schülerdaten eintragen.

## Installation

Die veröffentlichte App kann im Smartphone-Browser über **Zum Startbildschirm hinzufügen** installiert werden. Falls noch ein älteres Icon angezeigt wird, den bisherigen Startbildschirm-Eintrag löschen, die Seite neu laden und erneut hinzufügen.

## GitHub Pages

Die App ist für GitHub Pages auf `main` / `/(root)` vorbereitet. Alle Pfade sind relativ, der Service Worker arbeitet ausschließlich innerhalb des Repository-Pfads, und der Cache ist von anderen Apps auf derselben GitHub-Pages-Domain getrennt.
